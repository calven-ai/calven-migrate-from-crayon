# Repository instructions

calven-migrate-from-crayon is a dependency-free Node.js CLI that exports what a customer's own Crayon account can answer about each competitor, through Crayon's official MCP server, plus insights from Crayon's Insights API when the customer supplies a key.

- Keep it dependency-free. Node 20 built-ins only.
- Run `npm test` after every change.
- Never add Crayon material (screenshots, logos, copied help text, real answers or insights). Test data stays fictional.
- Use only Crayon's official MCP server and APIs. Never scrape or automate the Crayon web app: Crayon's terms forbid scripts that scrape the Services.
- Crayon has not published its MCP tool schemas or Insights API endpoints. Discover tool and argument names at runtime, never hard-code an endpoint as if it were documented, and degrade to a clear message or a flagged gap rather than a crash.
- The disclaimer in `README.md` and `src/cli.mjs` (`DISCLAIMER`) follows the one set by legal review for calven-migrate-from-klue. Change both together, and only with that review.
- Use Crayon's name only to say what the tool works with. No claims about Crayon beyond what its published terms and announcements say.
- Write without em dashes or en dashes.
- `docs/assets/hero-{light,dark}.svg` are generated by `python3 scripts/build-hero.py ../calven-ai-workspace/brand/library` from the brand tokens and the Calven wordmark. Re-run it rather than editing the SVGs. Never add a Crayon logo or Crayon colours.
